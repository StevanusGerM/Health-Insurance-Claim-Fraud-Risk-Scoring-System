# Health-Insurance-Claim-Fraud-Risk-Scoring-System
Health Insurance Claim Fraud Risk Scoring System: Pendekatan statistik dan pembelajaran mesin (LightGBM &amp; CatBoost) untuk mengesan, mengkuantiti, dan mengutamakan risiko penipuan tuntutan insurans kesihatan di bawah kapasiti audit yang terhad (5%) menggunakan metrik utama NormalizedRecall@5%.
